This repository contains functions that create simple mathematical formulas to model typical waves functions.


The outputs are float values for each of the input integers.


The files containing the functions are :

	sin_function.py
	sinc_function.py
	step_function.py


Usage:

	A list of real input values is provided by the user, for which the python functions 
	output the corresponding values of the transformation made by the mathematical model.


Used libraries include Numpy and Math.
No external tools are needed for the files to work.
